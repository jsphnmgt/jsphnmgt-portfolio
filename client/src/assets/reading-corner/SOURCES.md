# Pegboard photo sources

These are photographed product cutouts, not generated artwork. Original source files are preserved here; the runtime uses optimized WebP copies.

- `real-headphones.png`: [Headphone by diqqiafrizal, PurePNG](https://purepng.com/photo/5648/objects-headphone), published April 25, 2018. Source page states free for personal use, no attribution required.
- `real-plant.png`: [Artificial Potted Plant Oregano by PureNetwork, PurePNG](https://purepng.com/photo/28419/artificial-potted-plant-oregano). [Original asset](https://purepng.com/public/uploads/large/11232131312312-eke.png). PurePNG identifies its gallery as CC0.

Shelf brackets, hooks, pens, mesh cup, books and charms are built with CSS. No AI-generated artwork is used by the pegboard.
